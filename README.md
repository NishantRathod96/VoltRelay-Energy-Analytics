# VoltRelay Energy — Battery Swapping Network Operations Analysis

## Project Overview
An end-to-end data analytics project focused on analyzing battery swapping network operations, battery health, station performance, and customer experience.

## Project Objectives
- Analyze battery health and supplier performance.
- Evaluate battery swapping station operations.
- Identify operational bottlenecks.
- Analyze customer support trends.
- Generate data-driven business recommendations.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Visual Studio Code

## Key Analysis Areas
- Battery health and State of Health (SOH)
- Supplier and manufacturing lot performance
- Equipment performance and charging efficiency
- Battery swapping station operations
- Customer support and operational insights

## Repository Contents
- `VoltRelay_Analytics_Notebook_VSCode.ipynb` — Main analysis notebook
- `requirements.txt` — Required Python libraries

## How to Run
1. Clone or download this repository.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Create a folder named `data`.
4. Place the required CSV datasets inside the `data` folder.
5. Open the notebook in VS Code.
6. Select your Python environment and run all cells.

## Dataset Notice
The datasets are not included in this repository. You must provide the required CSV files locally to execute the notebook.
